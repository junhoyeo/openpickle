OpenPickle for Windows
======================

OpenPickle is an unofficial native desktop client for Pickle.

Install
-------
Extract this zip, then run OpenPickle.exe. Windows SmartScreen may show a warning because this
build is not code-signed. Choose "More info", verify that the app is OpenPickle, then choose
"Run anyway" if you trust this download.

Project: https://github.com/junhoyeo/openpickle
